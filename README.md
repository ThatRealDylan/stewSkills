# stewskills
Free useful skills to be used with Google Edge Gallery.

Current Skills you can Use:

#### (1.0v) stock-tracker - Track stocks
#### More coming soon!

To import skills:
1. Open the app and then Agent skills.
2. Click on the Skills button on the prompt box.
3. Click the (+) Icon and then select "Load Skill from URL"
4. Enter 'https://thatrealdylan.github.io/stewSkills/SKILL_NAME'. Replace "SKILL_NAME" With the name of the skill you want to use like 'https://thatrealdylan.github.io/stewSkills/stock-tracker'.
5. You're done! Skills like stock-tracker may require entering something in 'Secret'

### This is not a place on how to learn to create skills. For that, please go to the [Offical Skill Guide](https://github.com/google-ai-edge/gallery/blob/main/skills/README.md).
