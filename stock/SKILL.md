# Stock Tracker
Use this skill when the user asks for a stock price or how a company is doing on the market.

### Tools:
- **getStockPrice**: 
    - description: "Gets the current price and daily change for a stock ticker."
    - parameters:
        - symbol: "The stock ticker symbol (e.g., 'TSLA', 'MSFT')."
